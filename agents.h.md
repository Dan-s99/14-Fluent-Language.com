#   Historial de cambios

##    2026-04-22

- Se agregó a `AGENTS.md` una regla local de cierre documental obligatorio para cambios técnicos.
- Se dejó explícito que `project-documentation` no debe usarse solo como contexto cuando una intervención sí modifica código o comportamiento observable.
- Se aclaró que el registro técnico en `2_Code_Tools` debe actualizar la iteración vigente, sin abrir ni cerrar iteraciones por cuenta propia del agente.
- Se dejó explícito que `Changes` se llena en orden cronológico dentro de la iteración vigente y que `Objective`, `Tasks` y `Notes` también pueden ajustarse si hace falta mantener la iteración fiel al trabajo actual.

##    2026-04-13

- Se creó `AGENTS.md` para registrar reglas agénticas locales del proyecto.
- Se añadió la definición operativa de encapsulación de archivos Markdown.
- Se dejó explícito que una nota encapsulada debe vivir dentro de una carpeta dedicada con el mismo nombre del archivo y con sus recursos dependientes dentro del mismo contenedor.
