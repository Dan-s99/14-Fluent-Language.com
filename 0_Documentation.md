Este proyecto es para trabajar como profesor particular de inglés.

#   Principles of cohesion and coupling / scope

##    Cohesion

- Describir la estructura general del repositorio.
- Servir como puerta de entrada a la documentación del proyecto.
- Diferenciar documentación directiva, documentación técnica y archivos de trabajo concreto.

##    Coupling

- Se apoya en `1_Directive_Notes` para el conocimiento reusable del proyecto.
- Se apoya en `2_Code_Tools` para la documentación técnica y de implementación.
- Se apoya en `3_Files` para materiales operativos y trabajo aplicado.
- Se complementa con `0,5_tasks.md` para pendientes activos del repositorio.
