Esta nota define el criterio reusable para ofrecer, explicar y aplicar la `Evaluación de nivel (examen de colocación)` dentro de la academia particular de inglés de Orlando Lazos.

#   Principles of cohesion and coupling / scope

##    Cohesion

- Dejar claro qué es la evaluación de nivel, cuánto cuesta y qué partes la componen.
- Definir para qué sirve dentro del flujo comercial y académico del servicio `Inglés particular`.
- Fijar el criterio base para recomendar reducción de temario o selección de ruta.

##    Coupling

#   Propósito

La evaluación de nivel existe para que una persona no entre a una ruta completa sin necesidad cuando ya trae una base previa de inglés. Su función es ubicar mejor el nivel real del alumno y convertir ese diagnóstico en una recomendación práctica sobre:

- el curso más conveniente;
- el bloque o punto de entrada recomendado;
- la posible reducción del temario.

#   Estructura base de la evaluación

La evaluación de nivel tiene un costo de **$300 MXN**.

Se compone de dos partes:

1. **Examen escrito de colocación**
   El alumno lo responde por su cuenta, sin asistencia, para tener una referencia más limpia de lo que realmente domina.

2. **Evaluación oral**
   Después de revisar el examen escrito, se realiza una evaluación verbal de aproximadamente **30 minutos** para contrastar comprensión, soltura y nivel práctico.

#   Resultado esperado

Después de revisar ambas partes, Orlando puede recomendar:

- qué curso de la academia conviene más;
- desde qué parte del curso debe empezar el alumno;
- qué bloques o lecciones pueden omitirse;
- si conviene una ruta completa, parcial o distinta.

#   Criterio de reducción de temario

La reducción de temario no se ofrece como promesa automática, sino como consecuencia del diagnóstico.

La idea es poder decir algo como:

- que no hace falta recorrer el bloque básico completo;
- que conviene entrar directo a un bloque intermedio;
- que basta con tomar ciertas lecciones específicas;
- o que conviene irse a otra ruta como repaso gramatical, pronunciación o expresión.

#   Uso comercial y de UX

Esta evaluación debe comunicarse al usuario como una opción útil para:

- empezar desde su nivel actual;
- ahorrar tiempo si ya trae base;
- evitar pagar por contenido que no necesita;
- recibir una recomendación más precisa antes de arrancar.

En la página pública conviene nombrarla como **Evaluación de nivel (examen de colocación)** porque ese nombre se siente más claro para el usuario general.
